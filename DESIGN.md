# Aethera — Design System

**Vibe:** Playful, confident edtech. Neo-brutalist + high-contrast card blocks. Pill-everything. Distraction-free.

---

## 1. Color Palette

* **Base Surfaces:**
  * Charcoal (Dark UI): `#14151A`
  * Cream / White (Light UI): `#F6F3E7` / `#FFFFFF`
  * Ink / Border: `#000000` / `#0D1B4C`

* **Accent Palette:**
  * Lime: `#8ED14F` / `#06D6A0`
  * Coral: `#F26B5E` / `#FF70A6`
  * Mint: `#8FE3C5`
  * Amber: `#FFD166`
  * Lavender: `#C9B6F2` / `#9D4EDD`
  * Sky: `#4C6FF2` / `#118AB2`

---

## 2. Component Design Principles

* **Cards:** Neo-brutalist 3px solid black border (`border-3 border-black`), offset box-shadow (`shadow-brutal`), high-contrast colors.
* **Pills & Badges:** Full-pill radius (`rounded-full`), bold labels, icon prefix chips.
* **Inputs & Textareas:** Clean, auto-resizing text fields with instant quick-action autocomplete pills.
* **Typography:** Geometric rounded sans-serif font family (`Inter` / `Poppins`), heavy headers (700-800 weight), clear hierarchy.
